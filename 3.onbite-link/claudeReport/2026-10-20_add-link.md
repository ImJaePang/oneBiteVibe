## 동작 확인
- `/api/og?url=https://nextjs.org` → 제목/설명/썸네일 정상 추출 (200)
- `localhost` 등 내부 주소 → 422, `ftp://` → 422, 잘못된 URL → 400
- `tsc --noEmit` 통과. (`npm run lint` 는 기존 `eslint-config-next` 버전 불일치로 실행 불가 — 이번 변경과 무관)
- 브라우저에서의 저장 → 카드 표시 흐름은 직접 확인하지 못함.

## 참고 / 후속 과제
- 저장은 메모리(state)에만 반영되어 새로고침하면 사라짐 (폴더와 동일).
- 썸네일은 임의 도메인이라 `next/image` 대신 `<img>` 사용 (`remotePatterns` 로 모든 호스트를 열 수 없음).
- 보안: http(s)만 허용, DNS 조회 결과가 사설/루프백 IP 면 차단, 리다이렉트는 최대 3회(매 단계 재검사), 8초 타임아웃, 본문 1MB 제한. DNS 조회와 실제 연결 사이의 재바인딩까지는 막지 못함.
- 기존 mock 링크에는 썸네일이 없어 카드에 이미지가 표시되지 않음.
- 중복 링크 검사는 하지 않음. 폴더 삭제 시 해당 폴더의 링크 처리도 아직 없음.
