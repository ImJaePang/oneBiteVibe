# 링크 수정 기능 (2026-10-21)

요청: 링크 카드 호버 시 우측 상단에 연필 아이콘 → 클릭 시 폴더·제목·설명만 수정하는 모달 (`prompt.md`)

## 컴포넌트 목록

| 컴포넌트 | 파일 | 역할 | 종류 | 변경 |
|---|---|---|---|---|
| EditLinkButton | `components/EditLinkButton.tsx` | 카드 우측 상단(휴지통 왼쪽) 연필 버튼 + 모달 열림 상태 | Client | 신규 |
| EditLinkModal | `components/EditLinkModal.tsx` | "링크 수정" 모달. 폴더/제목/설명 state 를 현재 값으로 채우고 저장 시 `updateLink` 호출. 제목이 비면 저장 안 함 | Client | 신규 |

## 재사용한 기존 컴포넌트
`Modal`, `FolderSelect`, `SaveButton`, 공통 CSS(`.folder-action`, `.folder-edit`, `.field`, `.btn-secondary`) — CSS 변경 없음.

## 참고 / 후속 과제
- 수정도 메모리(state)에만 반영되어 새로고침하면 복원됨.
- 다른 폴더로 옮기면 현재 폴더 목록에서 카드가 사라지고 대상 폴더에서 보임.
- URL·썸네일은 수정 대상이 아니라 그대로 유지.
- 브라우저에서 호버/모달 동작은 직접 확인하지 못했고 `tsc --noEmit` 결과만 확인.
