링크스테이블과 폴더스테이블을 연결해줘

- 링크 테이블에 folder_id라는 컬럼을 추가해줘
- folder_id 컬럼은 선택적 컬럼으로 설정해줘
- folder_id 컬럼이 folders 테이블의 id 컬럼을 참조하도록 외래키로 설정해줘
- folders 테이블의 데이터가 삭제될 경우 (폴더 삭제) 연결된 links 테이블의 folder_id를 비워줘.

- 컴포넌트 단위로 적절히 분할해서 구현
- 이미 만들어둔 컴포넌트를 최대한 활용해
- 결과는 컴포넌트 단위로 보고해 - claudeReport폴더에 파일로 정리하면 좋겠다. 그래서 실행할 때마다 이전 내용 확인해서 볼 수 있게.
