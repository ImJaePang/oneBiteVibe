링크 추가 기능을 구현해줘

- 먼저 특정 링크의 오픈 그래프 정보를 추출하는 API를 구현해
- 새 링크 페이지에서 확인 버튼을 누르면 링크를 저장해
  오픈 그래프 API를 통해서 링크의 핵심 정보인 제목, 설명, 썸네일, 링크 주소를 함께 수집해서 저장해줘
- 새롭게 보관되는 링크 카드에 썸네일도 함께 표시해줘

# 주의 사항

- 컴포넌트 단위로 적절히 분할해서 구현
- 이미 만들어둔 컴포넌트를 최대한 활용해
- 결과는 컴포넌트 단위로 보고해 - claudeReport폴더에 파일로 정리하면 좋겠다. 그래서 실행할 때마다 이전 내용 확인해서 볼 수 있게.
